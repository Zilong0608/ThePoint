# THE POINT 上线配置说明

## 数据保存在哪里

目前使用 SQLite（storage/data.sqlite）保存文章、房源、账号、收藏等，上传图片在 storage/uploads 目录。后台网页是编辑界面，保存后由服务器写入数据库，再给前台读取。SQLite 无需数据库订阅，但服务器和备份存储需要独立安排。

## 域名与正式站点 URL

域名可以在 Metaname（https://www.metaname.co.nz/）或 Cloudflare Registrar 购买。先查询名称是否可注册，核对续费价格，使用自己的账号持有域名。购买域名并不包含网站服务器或邮箱收件箱。

正式站点 URL 是用户访问网站的完整地址，例如 https://example.co.nz。这只是示例，需要换成自己的域名。上线后填写后台相应设置，或配置 PUBLIC_SITE_URL。它用于重置密码链接、网页规范地址等，不要在正式环境填 localhost。后台已有设置时应同时检查，避免覆盖环境变量。

## 发信邮箱

重置密码需要 SMTP 服务。可以使用已有企业邮箱提供的 SMTP，或开通 Resend，添加自己的域名并按其提示在域名 DNS 中添加验证记录，待验证通过后创建发信 API key。

Resend SMTP 示例（https://resend.com/docs/send-with-smtp）：

```ini
SMTP_HOST=smtp.resend.com
SMTP_PORT=465
SMTP_USER=resend
SMTP_PASS=替换成你自己的Resend_API_KEY
SMTP_FROM=THE POINT <no-reply@example.co.nz>
PUBLIC_SITE_URL=https://example.co.nz
```

SMTP_FROM 必须属于已验证的域名。SMTP_PASS 是服务商凭据，不是网站登录密码。也可以在管理后台填写，避免把凭据提交到代码仓库。发送服务和人工收件箱用途不同；需要接收客户来信时另设业务邮箱。

## HTTPS

如果使用自己的 Linux 服务器，可用 Caddy 自动申请和续期证书。将域名 A 记录指向服务器公网 IP，开放 80/443，网站 Node 服务仅通过本机或内部网络提供给 Caddy。Caddyfile 示例：

```caddyfile
example.co.nz {
    reverse_proxy 127.0.0.1:3000
}
```

网站配置 PUBLIC_SITE_URL=https://example.co.nz、COOKIE_SECURE=1。仅在请求确实经过可信反向代理且 Node 未直接暴露时启用 TRUST_PROXY=1。Caddy 的配置和证书目录也需要持久保存。若使用托管平台，优先使用平台提供的域名绑定和 HTTPS 功能。

官方流程：https://caddyserver.com/docs/quick-starts/https

## 异机备份

目前自动和手动备份都写入本机目录；它们还不是异机备份。不要只备份源代码，也不要把正在写入的 SQLite 文件单独拖走。

1. 在项目目录执行 `node scripts/backup.js`，或点击后台的完整备份按钮。
2. 将生成的完整备份文件夹（包含 data.sqlite、uploads、manifest.json）复制到另一台机器或自己的云盘。备份包含私人资料，应限制访问；自动同步时建议加密。
3. 下载回来后执行 `node scripts/backup.js verify "备份目录"`。
4. 定期在新空目录演练恢复：`node scripts/backup.js restore "备份目录" "新的空数据目录"`。恢复生产服务前先停止原服务，检查恢复结果，再切换 TP_DATA_DIR。

正式运行后建议每天自动传到独立存储，保留最近 7 份日备份及 4 份周备份，并记录失败告警。具体自动上传配置取决于你选择的云盘或对象存储，现在尚未接入外部账号。

## 收藏房源

找房列表和房源详情可收藏；个人中心点击“我的收藏”查看或取消。收藏按登录账号保存，可跨设备使用。未登录时会先进入登录页面，下架或删除的房源不再展示内容，可移除失效收藏。请使用 Node 服务访问，旧的静态演示版已移除。

## 地图找房与房源位置

找房页面默认显示地图与列表。输入 Albany 等地区名称后点击搜索，地图与列表同步筛选；也可叠加用途、价格、卧室等条件。地图标记显示价格，点击查看图片和详情，位置相近的房源会合并为数量标记，放大后展开。地图展示全部匹配位置，不受列表分页影响；单次最多 1,000 个位置，超出时会提示缩小搜索范围。

新增房源：后台 → 房源管理 → 新增房源 → 填写地址、Suburb、City → 点击“按地址定位” → 选择匹配结果 → 检查地图圆点，必要时点击地图或拖动圆点校正 → 保存。也可直接填写经纬度。没有定位的房源只进入列表；已有房源也需要确认一次地图位置。修改地址后应重新定位。

地图使用本地打包的 Leaflet 1.9.4；底图默认由 OpenStreetMap 提供。地址查询默认使用 Photon，只在管理员点击按钮时发送填写的地址，结果缓存 30 天，请勿在地址字段填写客户隐私资料。用户搜索 Albany 时仅查询本站数据库，不向地址服务发送用户搜索词。

Photon 公共演示服务允许合理请求量，但不保证可用性，详见 https://github.com/komoot/photon#demo-server 。后台查询已限流、缓存，失败时可手动选点。可通过 GEOCODER_URL 更换兼容的 Photon 服务。底图受 https://operations.osmfoundation.org/policies/tiles/ 约束，不做离线下载或批量预取；访问增长后可通过 MAP_TILE_URL 和 MAP_ATTRIBUTION 更换服务。无需为当前方案填写 Google Maps API Key，但公共服务没有可用性保证。
