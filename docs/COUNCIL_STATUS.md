# 物业查询交付范围

本地入口：`/council.html`。数据来自官方公开服务，没有将测试记录写入业务数据库。

结果默认显示地块、土地分区及通用规划变更。用户可在“选择想看的资料”中勾选其他类别，地图、状态及结果同步显示；选择保存在当前浏览器。显示切换复用本次查询，不重新请求官方数据。下载本次资料仍包含完整查询结果，并记录当前选择的类别。

“未返回相交记录”表示该图层成功查询但没有与查询范围相交的记录；“服务暂时不可用”表示无法取得资料，结论未知。管网在道路内等地块外的情况不会计入地块相交结果。

## 已接入

| 类别 | 内容 |
| --- | --- |
| 地址与地块 | 奥克兰现行地址、主地块边界、编号、法定描述、记录面积、关联产权编号 |
| 分区 | 官方基础分区及记录状态，区分地址点所在范围与其他地块相交范围 |
| 规划变更 | 官方通用变更图层、对应文件链接、第120号详细摘要；提示新公告与旧摘要的区别 |
| 相关规划 | 特别规划区、指定用途、附加高度控制、官方地区／结构规划项目范围和文件 |
| 风险 | 洪泛区、易积水区、地表径流路径，明确相交／无返回／未知三种情况 |
| 管网 | 雨水管线、本地供水和污水管线；不推算容量或接入权利 |
| 规划文件维护 | 后台增删改、公开／隐藏、文件日期、导入范围多边形、版本冲突保护 |
| 展示工具 | 中英文、手机布局、分类导航、图层开关及记录定位、查询分享、资料下载、打印 |

唯一相交、有效且非道路／水域的主地块会自动用于范围查询。多个地块必须选择，不能把公寓的主地块当成独立单元产权。

## 本次不包含的资料

- 完整产权证书及产权人资料。
- 全量建筑、资源许可历史和正式土地信息备忘录。
- 估值、成交、商业房源数据库。
- 全部传输管线、私有设施和工程探测结果。
- 全奥克兰每份规划文件的完整适用范围或全部规划变更。
- 自动判断可建栋数、可分割面积或开发许可结论。

这些缺口不能用其他年份的许可样本、邻居资料、地区名称推断或模拟数据替代。扩展时必须核实正式数据来源、访问条件及字段含义。普通公开图层不需要用户另购会员；受控数据应按其来源的条件接入。

## 验收与上线

自动检查：`npm run check`、`npm test`、`npm run test:browser`。测试使用独立临时数据库和浏览器响应；官方服务另行做真实查询验收。

已真实核验三个现有／用户提供的地址，覆盖公寓主地块和乡村地块，并观察到管线、洪水及结构规划的正例。官方服务仍可能调整字段、链接或暂时不可用，页面会保留未知状态。

部署采用现有 Node、SQLite 和持久磁盘，不需要迁移至 Supabase。推送代码后，Render 需部署对应提交；已有数据库会自动补齐规划文件范围与日期字段，业务内容不会被测试数据替换。
